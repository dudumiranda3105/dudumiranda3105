## Sobre mim

Sou estudante na **Uni-FACEF**, em Franca (SP), com foco em desenvolvimento Android usando **Kotlin e Java**. Também desenvolvo aplicações web completas, do banco de dados à interface.

Meus projetos partem de problemas concretos: um app Android que recomenda lugares próximos com IA, um sistema de recebimento de mercadorias feito em hackathon para uma cooperativa, o monitoramento de uma sala de servidores com manutenção preditiva e uma extensão de Chrome distribuída por releases.

Estou aberto a oportunidades em desenvolvimento Android e web.
