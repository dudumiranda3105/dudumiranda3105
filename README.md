## Sobre mim

Sou estudante da **Uni-FACEF**, com foco em desenvolvimento Android usando **Kotlin e Java**. Também desenvolvo aplicações web e ferramentas para o dia a dia.

Entre meus projetos estão uma biblioteca de jogos para web e mobile, uma plataforma de vagas desenvolvida em equipe e uma extensão para assistir à Crunchyroll em uma janela flutuante.

---

## Projetos em destaque

### [GameDex](https://github.com/dudumiranda3105/GameDex)

Aplicação para descobrir jogos e organizar uma biblioteca pessoal, com favoritos e status de progresso. Tem versões web e mobile, usando dados da RAWG.

**React · React Native · Expo · Firebase**

[Ver projeto e instruções de acesso](https://github.com/dudumiranda3105/GameDex#readme)

### [ConectaPCD](https://github.com/dudumiranda3105/ConectaPCD)

Projeto acadêmico desenvolvido em equipe na Uni-FACEF para conectar pessoas com deficiência a oportunidades de trabalho. Inclui perfis de candidatos, publicação de vagas e gestão de candidaturas.

**TypeScript · Node.js**

[Conhecer o projeto](https://github.com/dudumiranda3105/ConectaPCD#readme)

### [PiP para Crunchyroll](https://github.com/dudumiranda3105/PiP-Crunchyroll)

Extensão para Chrome que adiciona um botão de Picture-in-Picture ao player. Abre o vídeo em uma janela flutuante, sem coleta de dados. Projeto independente, sem vínculo com a Crunchyroll.

**JavaScript · Chrome Extensions · Manifest V3**

[Baixar a extensão](https://github.com/dudumiranda3105/PiP-Crunchyroll/releases/latest)
